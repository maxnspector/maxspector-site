The site loads a self-hosted variable font at:  /fonts/playfair.ttf

How to get it (one time, ~1 minute):
1. Go to  https://fonts.google.com/specimen/Playfair
   (this is "Playfair" — NOT "Playfair Display")
2. Click "Get font", then "Download all". You'll get a .zip.
3. Open the .zip. Find the file named:  Playfair[opsz,wdth,wght].ttf
4. Rename that file to exactly:  playfair.ttf
5. Put it in this fonts/ folder (you can delete this README).

That's it — the site uses your exact settings (optical size 10, width 103,
weight 400) automatically.
